# Wind格式漂移自愈SOP

## 原则

大模型可以兜底理解新格式，也可以提出并修改适配代码，但不能绕过原始值校验、单位校验、测试和可回滚要求。模型是结构解释器和代码生成器，不是金融数据源。

## 分级流程

### L0：确定性适配

先运行 `wind_response_adapter.py`。别名、信封或表格形态已覆盖时直接完成，不调用模型。

### L1：模型字段映射

适配失败后读取脱敏原始回包与生成的fallback请求。模型只输出候选对象：

```json
{
  "record_path": ["data", "records"],
  "profile": "stock",
  "fields": {
    "code": {"source_key": "证券Wind代码"},
    "main_yuan": {"source_key": "当日主力净额", "unit": "万元"}
  }
}
```

确定性适配器依据候选路径重新从原始回包取值、换算和校验。候选不能携带市场数值。

### L2：受限代码适配

复杂嵌套结构无法仅靠字段映射表达时，模型可以生成仅含一个 `adapt(raw)` 函数的Python文件。先运行：

```bash
python scripts/validate_generated_adapter.py --adapter proposed.py --input raw.json --profile stock --output normalized.json
```

沙箱拒绝文件、网络、进程、导入、反射、递归和危险内建函数。函数只返回候选映射；最终值仍由确定性适配器从脱敏原始回包回读。

### L3：永久代码修复

同一种新格式重复出现，或L1/L2已验证成功时，模型可修改本仓库 `wind_response_adapter.py`：

1. 将脱敏回包最小化为测试fixture，不提交任何密钥、接收标识或不必要业务数据。
2. 补充能复现旧失败的新测试，并确认旧格式测试仍通过。
3. 把通用规则加入信封/形态识别或语义别名，不为单次值写特例。
4. 运行全量单元测试、语法检查和Skill快速校验。
5. 代码评审后发布新Skill版本；失败可回滚到上一个版本。

## 禁止事项

- 不允许模型直接填写缺失金额、日期、排名、涨跌幅或单位。
- 不允许把解析失败改写成空数组并标记成功。
- 不允许运行未经 `validate_generated_adapter.py` 验证的生成代码。
- 不允许自动提交、推送或发布永久代码变更；这些操作需遵循仓库审批流程。
- 不允许格式适配改变盘中档位、报告频率、计算公式或交付目标。

## 运行状态

适配失败时档位记录 `pending_adapt`，并保存脱敏原始回包、错误分类、fallback请求和已尝试层级。L1/L2成功后继续原档计算和交付；若仍失败，保留待重试，不发送残缺报告、不占用完成档位。
